# MAZE RACE — 50 人迷宮競速手機網頁遊戲

## 本機啟動

1. 安裝 Node.js 20 或更新版本。
2. 在專案資料夾執行 `npm install`。
3. 執行 `npm start`。
4. 用電腦瀏覽器開啟 `http://localhost:3000`，點「我是主持人」。

## 公開部署（Render 範例）

1. 將整個專案上傳到私人或公開 GitHub repository（不要上傳 node_modules）。
2. Render → New → Web Service → Connect GitHub repository。
3. Runtime 選 Node，Build Command 設 `npm install`，Start Command 設 `npm start`。
4. 部署完成後開啟 Render 提供的 HTTPS 網址，建立房間。
5. 主持人畫面會顯示當前房間專用 QR Code，參賽者掃碼、輸入暱稱加入。
6. 人員到齊後主持人按「開始比賽」，所有人取得同一迷宮並倒數開賽。

## 功能

- 最多 50 位參賽者／房間；每位參賽者須獨立裝置及連線。
- 同房間共享相同的隨機生成迷宮；起點左上、終點右下。
- 伺服器驗證移動是否撞牆，並以伺服器時鐘記錄完成時間。
- 主持人開局、倒數、排行榜與下一場重置。
- QR Code 連結隨網站部署網域自動生成。

## 上線注意

- 房間及排行榜目前只保存在伺服器記憶體，伺服器重啟即清空；主持人離線房間關閉。
- 本版本適合單一 Node.js 實例；**請勿開啟多實例水平擴充**，否則須改用 Redis adapter + 共用狀態。
- 免費主機可能休眠，活動前先開啟網站暖機；正式活動建議選用穩定的付費實例。
- 50 人同時遊玩是設計上限，實際效能與 Wi-Fi 品質須在活動前壓測。
- 沒有帳號系統、防作弊身份驗證、持久資料庫或斷線續玩。比賽結果不適合獎金競賽或高風險用途。
- 使用 HTTPS 才能確保掃碼後在各種手機瀏覽器正常連線。
